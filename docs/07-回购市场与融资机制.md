# 07 · 回购市场与融资机制

> **这份文档定义本作最核心、也最被低估的系统。**
>
> 如果只做一件事让这个游戏区别于其他交易游戏，那就是它：**2008 年杀死机构的不是股价下跌，是融资断裂。**

---

## 1. 为什么回购市场是核心

大多数金融危机游戏把"暴跌"当成主要威胁。这是错的。

2008 年的真实机制是：

```
你持有的资产没变，价值也没有立刻归零。
但明天你必须为到期的回购融资展期——
而今天没有人愿意借钱给你了。
于是你被迫卖出。
卖出压低价格。
价格下跌让 haircut 上升，融资能力进一步下降。
你被迫卖出更多。
```

**贝尔斯登、雷曼、AIG 都不是被"亏损"杀死的，是被"展期失败"杀死的。**

- 贝尔斯登在 2008-03-13 至 03-14 两天内被回购方抽走约 **170 亿美元**融资，在此之前它的资本充足率是达标的。
- 雷曼的回购融资规模约 **2000 亿美元**。它倒下时账面净资产仍为正。
- AIG 的证券借贷项目规模约 **750 亿美元**，借来的现金被投进了 MBS。该项目在 9 月遭遇挤兑。

> **这就是本作的教学核心：不是你判断错了，是你在正确的时候被融资断了。**

## 2. 回购机制基础

### 2.1 什么是回购

```
今天：你把抵押品卖给对手方，借到现金
明天：你以略高的价格买回抵押品（差额 = 回购利息）

抵押品市值 × (1 − haircut) = 你能借到的现金
```

`haircut`（折扣率）是整套机制的关键变量。**它衡量的是"市场认为这个抵押品有多安全"。**

| 抵押品类型 | 平静期 haircut | 危机期 haircut |
|---|---|---|
| 美国国债 | 0–2% | 3–5% |
| 机构 MBS | 2–5% | 10–20% |
| AAA 私有标签 RMBS | 5–10% | 45–100% |
| CDO / 结构化产品 | 10–20% | **100%（完全无法融资）** |

**关键洞察**：haircut 从 5% 涨到 45%，意味着同样 1 亿美元的抵押品，能借到的钱从 9500 万变成 5500 万。**缺口 4000 万必须立即补上，方法是卖资产。** 而所有人同时卖，价格就崩了。

### 2.2 三方回购（Tri-party repo）

现实中大部分回购通过三方回购市场完成：由两家清算银行（摩根大通、纽约梅隆）居中处理抵押品。

| 特征 | 数值 |
|---|---|
| 三方回购市场规模（2008） | 约 2.8 万亿美元 |
| 清算银行 | **仅两家** |
| 日间信用 | 清算银行每天向交易商提供巨额日间授信 |

**这带来一个巨大的系统性隐患**：如果清算银行撤出日间授信，整个回购市场会在**一天之内**停止运转。这是整个金融体系里最集中的单点故障。

### 2.3 谁在出借

回购市场的资金主要来自：

| 出借方 | 行为特征 |
|---|---|
| 货币市场基金 | 最大来源。它们一撤，市场就没了 |
| 证券借贷部门 | 基金把持仓借出去换现金，再拿现金做回购 |
| 外国央行与主权基金 | 危机中撤得最快 |
| 企业现金管理部门 | 保守，最先跑 |

**共同点：它们都极度厌恶风险，且没有义务留在市场里。** 一旦有任何疑虑，它们会在几小时内消失。

## 3. 回购挤兑的五个阶段（历史时间线）

本作的回购事件卡严格按这个阶段划分。

### 阶段一 · 裂缝（2007-08 → 2007-12）

- ABCP（资产支持商业票据）市场关闭，1.2 万亿规模萎缩至 8000 亿
- 结构化产品 haircut 从 0–5% 跳升至 10–20%
- 回购期限从 3 个月缩短到**隔夜**——这是最危险的信号，因为隔夜融资意味着对方每天都可以选择不续
- 巴黎银行冻结基金（2007-08-09）是触发点

**玩家应该看到**：K 线还在创新高，但回购折扣率在涨。这是一个只有 D2 玩家能看见的信号。

### 阶段二 · 第一次挤兑（2008-03）

- 贝尔斯登两天内被抽走 170 亿美元
- 回购方包括 Fidelity、Vanguard 等大型货币基金，它们直接停止对贝尔斯登出借
- 美联储在 03-11 推出 TSLF，03-16 推出 PDCF（允许一级交易商用 MBS 换国债）

**教训**：当出借方的**风险委员会**（而不是交易员）决定撤退时，速度是小时级的。

### 阶段三 · 全面冻结（2008-09）

这是整个危机最剧烈的一周：

| 日期 | 事件 |
|---|---|
| 09-07 | 两房被接管 |
| 09-11 | 雷曼回购融资被撤 |
| 09-15 | 雷曼破产 |
| 09-16 | AIG 被救助；Reserve Primary 跌破面值；**AIG 证券借贷项目遭挤兑** |
| 09-17 | 货币基金一周撤出 3000 亿美元 |
| 09-18 | 三方回购市场冻结；美联储 PDCF 扩容，**首次接受股票作为抵押品** |
| 09-19 | 财政部为货币基金提供担保；SEC 做空禁令 |
| 10-07 | 商业票据融资工具（CPFF） |

**结构化产品 haircut 在此阶段从 20% 跳到 45%，部分直接到 100%（完全无法融资）。**

### 阶段四 · 火售螺旋（2008-10 → 2008-12）

```
对冲基金与交易商被迫卖出
  → 价格下跌
  → 抵押品市值下降
  → haircut 上升
  → 融资缺口扩大
  → 被迫卖出更多
```

**这个循环自我强化，且没有自然停止点。** 唯一让它停下来的是政府介入：担保、注资、CPFF、QE。

### 阶段五 · 恢复（2009）

- 2009-06 起 haircut 逐步回落，回购期限开始拉长
- 恢复的标志不是股价上涨，而是**融资期限从隔夜变回一个月**

## 4. 数值模型

### 4.1 融资容量

```
RepoCapacity(player) = Σ_i 抵押品_i 市值 × (1 − haircut_i) × eligibility_i
```

- `eligibility_i` = 该抵押品是否被回购方接受（危机中许多资产的 eligibility 直接变成 0）
- haircut 按抵押品类别区分，不是全局一个值

### 4.2 挤兑触发

每个机构（含玩家）每天面临展期决策：

```
rolloverRate = clamp(baseRate × confidenceFactor × (1 − systemicStress), 0, 1)

融资缺口 = 今日到期回购 × (1 − rolloverRate)
```

若 `融资缺口 > 现金 + 可用信贷额度`：

```
→ 触发被迫卖出（fire sale）
→ 卖出量 = 缺口 / (1 − 抛售滑点)
→ 若仍不足 → 违约 → 破产/接管
```

`baseRate` 平静期 ≈ 1.0（几乎全额展期），危机期可降到 0.2 以下。

### 4.3 Haircut 演化（分段阶跃，不是连续函数）

历史数据显示 haircut 是**阶跃式**跳升的，不是平滑演化的。所以用分段函数而不是连续模型：

```
haircut_i(t) =
    base_i                                              当 systemicStress < 0.3
    base_i + 0.15                                       当 0.3 ≤ stress < 0.5
    base_i + 0.40                                       当 0.5 ≤ stress < 0.7
    min(1.0, base_i + 0.75)                             当 stress ≥ 0.7
```

**为什么用阶跃**：平滑函数会让玩家产生"可以慢慢应对"的错觉。阶跃制造的是"一夜之间缺口出现"的真实恐惧。**这个设计细节直接决定了游戏的情绪质感。**

### 4.4 系统性压力

```
systemicStress = w1·norm(creditSpread) + w2·norm(tedSpread) + w3·norm(vix) + w4·(1 − liquidity)
w = [0.35, 0.25, 0.20, 0.20]
```

它同时驱动：haircut、rolloverRate、所有 NPC 的 riskAppetite、以及事件卡的 `state` 型触发器。

## 5. 玩家面对的回购规则（D2+）

### 5.1 玩家也有回购容量

**这是本作最重要的机制设计。** 玩家不能只是"有钱就买"，他有一个独立的融资维度：

```
融资容量    = 持仓抵押价值 × (1 − 当前 haircut)
今日到期    = 昨日融资余额
展期率      = f(你的信用状况, 市场压力, 你的 SRS)
融资缺口    = 今日到期 × (1 − 展期率)
```

### 5.2 三种应对方式

| 方式 | 代价 |
|---|---|
| 补充抵押品 | 需要现金，且危机中现金最贵 |
| 主动减仓 | 在坏价格上卖出，但可控 |
| 什么都不做 | 引擎替你强平，价格最差且带惩罚滑点 |

**这就是本作的核心决策三角。** 它不是"买还是卖"，而是"**怎么活到明天**"。

### 5.3 玩家的信用状况

```
玩家展期率 = 0.95
             − 0.40 × systemicStress
             − 0.30 × 玩家杠杆超标程度
             − 0.25 × 玩家 SRS
             + 0.10 × (无违约历史)
```

**注意最后一项**：如果你的 SRS 高（被监管盯上）或杠杆高，**你的融资成本会上升**。这让"资金过大"的惩罚不只是监管，还有更贵的钱。与 [03 §8](03-金融模型与数值.md) 的监管阶梯形成合力。

### 5.4 与做空的交互

做空需要借券，而借券来自证券借贷部门——**它同时也是回购市场的出借方**。

当证券借贷部门撤退时：

```
借券费飙升（年化 0.5% → 20%+）
可用券源枯竭（shortable = false）
已建立的空头可能被强制回补（lender recall）
```

**强制回补是逼空的燃料。** 当大量空头同时被召回，买入压力会让价格暴涨——这在 2008-10 和 2009-03 都真实发生过。

## 6. UI 呈现要求

回购机制**必须可见**，否则玩家只会觉得"莫名其妙被强平了"。

主界面常驻「融资面板」：

```
融资状况
├─ 抵押品价值        $  8,420,000
├─ 加权 haircut          32%   ▲ +27pp（30 天前 5%）
├─ 融资容量          $  5,725,000
├─ 已用融资          $  5,100,000
├─ 剩余额度          $    625,000   ⚠ 紧张
├─ 今日到期          $  1,200,000
├─ 预计展期率            68%   → 缺口 $384,000
└─ 建议动作         补抵押 / 减仓 / 承受强平
```

**haircut 那一行的变化箭头是最重要的信息。** 它应该在危机前就开始跳动，给 D2 玩家一个 D0 玩家看不见的预警。

## 7. 与其他系统的接口

| 系统 | 交互 |
|---|---|
| 事件卡 | `impact.repoHaircutDelta` 驱动 haircut 阶跃；`liquidityMultiplier` 驱动展期率 |
| 系统性风险分 | 玩家 SRS 影响自己的展期率（融资成本惩罚） |
| NPC | 出借方（货币基金）与借入方（交易商）都需要建模；出借方的撤退就是挤兑 |
| 期权定价 | 抵押品价值波动 → 对手方风险溢价 → CDS 利差 → 隐含波动率 |
| 强平 | 融资缺口无法补足 → 被迫卖出 → 若仍不足则违约 |
