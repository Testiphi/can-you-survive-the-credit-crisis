## 1. 价格生成

### 1.1 三层结构

```
最终价格 = 基础历史路径 × 事件冲击 × (1 + 路径噪声) × (1 + 玩家/NPC 冲击)
```

| 层 | 来源 | 作用 |
|---|---|---|
| 基础路径 | 真实历史数据（对数收益） | 保证整体走向符合历史 |
| 事件冲击 | 事件卡 `ImpactVector` | 让危机有"事件驱动"的节奏 |
| 路径噪声 | 跳跃扩散（GBM + Poisson jump） | 让每天都不一样，K 线看起来真实 |
| 冲击成本 | 玩家 + NPC 净流量 | 让规模有重量 |

### 1.2 跳跃扩散

```
r_t = (μ − λk − σ²/2)·Δt + σ·√Δt·Z + Σ Y_i     Z ~ N(0,1)
```
- `σ` 来自历史实现波动率（危机期自动上升）
- `λ` = 跳跃强度（次/年），平静期 2，危机期 30
- `Y` ~ 跳跃幅度，危机期均值 −6%，标准差 4%
- 加入**跳空**：暴跌日直接以大幅低开成交，不允许玩家"在盘中止损"

**这一条很重要**：真实危机中，最大的损失发生在开盘跳空。让玩家体验"我设的止损根本没触发，直接跳过去了"，比任何说教都有效。

### 1.3 波动率与相关性（★ 关键技术选择）

**不要直接维护相关矩阵。用单因子模型。**

```
r_i = β_i · F_market + √(1 − β_i²) · ε_i        ε_i ~ N(0, σ_i²)
```

- `F_market` = 市场共同因子，其方差在危机期放大（σ_F 从 1% 升到 5%）
- `β_i` = 个股对市场的敏感度

**为什么这是关键**：当 `F_market` 的方差放大时，所有股票的共同成分主导了各自的收益，**相关性自动趋近于 1**。

- 平静期：ρ ≈ 0.25
- 危机期：ρ ≈ 0.90

你不需要写一行"相关性上升"的代码，它是因子模型的自然涌现。**这是实现"分散化失效"这一课最简洁、最正确的方式。**

### 1.4 价格生成参数表（初值）

| 参数 | 平静期 | 危机期 |
|---|---|---|
| 日波动率 σ | 1.0% | 4.0% |
| 跳跃强度 λ（次/年） | 2 | 30 |
| 跳跃均值 | −1% | −6% |
| 市场因子 σ_F | 1.0% | 5.0% |
| 隐含相关性 | ~0.25 | ~0.90 |

## 2. 信用模型（CDS 的正确用法）

### 2.1 核心立场

**CDS 利差不是一个让玩家去读的数据，而是一个会自己发力气的机制。**

数据上不要试图还原真实单名 CDS（收费且无免费替代）。用 FRED 的 `BAMLH0A0HYM2`（高收益债期权调整利差）作为行业信用利差基准，按公司属性映射：

```
spread_company = spread_industry × β_credit
β_credit = f(rating, leverage, equity_vol)
```

### 2.2 正反馈循环（这是 2008 年的引擎）

```
利差上升
  → 融资成本上升（repo haircut 上升、发债成本上升）
  → 盈利预期下修 / 流动性担忧
  → 股价下跌
  → 评级下调
  → 利差再上升   ← 回到起点
```

同时叠加：

```
股价下跌 → 市值缩水 → 杠杆率被动上升 → 评级下调 → 融资更难 → 被迫抛售 → 股价再跌
```

**玩家体验到的应该是："某公司股价莫名在跌，三天后信用利差数据更新，我才明白为什么。"** 滞后、模糊、但因果真实。这远比给一条漂亮的利差曲线有价值。

### 2.3 违约强度

简化模型（不需要完整的生存曲线）：

```
λ_default = spread / (1 − R)          R = 回收率，金融业取 0.40
年化违约概率 ≈ 1 − e^(−λ_default)
```

### 2.4 评级迁移与被动卖出

评级下调触发**机械性抛售**：大量机构章程规定不得持有非投资级债券/股票。

```
AAA → AA → A → BBB → BB → B → CCC → D
```

当某机构被下调至 BBB 以下，持有它的保守派基金 NPC **被迫卖出**，与观点无关。

**这是"被迫卖出"最重要的载体，必须建模。** 2008 年大部分抛售不是因为看空，是因为必须卖。

## 3. 期权

### 3.1 定价：Black-Scholes，绝不用蒙特卡洛

```ts
function bsPrice(S, K, T, r, sigma, type): number
```

蒙特卡洛期权定价会让单回合耗时从微秒级变成毫秒甚至秒级，且精度并不更好。**用解析解。**

### 3.2 隐含波动率曲面（★ 必须做对，否则游戏被套利）

**这是 P2 最容易翻车的地方。** 2008 年 10 月 VIX 收盘峰值 **80.86**（2008-11-20），盘中峰值 **89.53**（2008-10-24）。如果你的引擎用固定 IV（比如 20%）给期权定价，玩家会买入跨式/虚值看跌，一夜暴富，游戏直接结束。

**参数化曲面（不需要 SVI 那么复杂）：**

```
ATM_IV  = f(VIX)                     例如 ATM_IV = VIX/100 × 0.95
skew(k) = 1 + a·(k) + b·(k)²         k = ln(K/S) / (σ√T)   （对数货币度）
IV(K,T) = ATM_IV × skew(k) × term(T)
```

参数建议：

| 参数 | 平静期 | 危机期 | 含义 |
|---|---|---|---|
| a（skew 斜率） | 0.15 | 0.45 | 虚值看跌更贵 |
| b（曲率） | 0.05 | 0.25 | 尾部更肥 |
| ATM_IV | 15–20% | 60–85% | 跟随 VIX |
| term（期限结构） | 平 | 倒挂（近月 > 远月） | 危机时近月 IV 高于远月 |

**危机时期限结构倒挂是真实特征，也是重要的一课**：短期恐慌远大于长期恐慌。

### 3.3 合约数量必须砍

| 维度 | 真实市场 | 本作 |
|---|---|---|
| 到期日 | 每周 + 每月 + LEAPS，几十个 | **3 个**（1 / 3 / 6 个月） |
| 行权价 | 上百个 | **5 个**（深度虚值 / 虚值 / 平值 / 实值 / 深度实值） |

"深度期权"的含义通过那 2 个极端档位体现就够了。**不要再加了，UI 会变成 Excel。**

一个标的 = 15 个合约。40 个标的 = 600 个合约。BS 定价 600 次 ≈ 120 微秒，可忽略。

### 3.4 教育价值最高的体验

**深度虚值看跌期权到期归零。**

玩家在 9 月花 50 万买看跌，10 月账面翻 8 倍（浮盈 400 万），若不平仓——12 月 IV 崩塌 + 时间衰减 + 市场反弹——归零。

**这是最痛、也最有价值的一课。** 必须确保引擎正确建模 `T → 0` 时的衰减，且到期结算清晰可见。

### 3.5 数值边界

- `T ≤ 0` → 返回内在价值 `max(S−K, 0)` 或 `max(K−S, 0)`
- `σ ≤ 0` → clamp 到 1e-4
- 深度虚值 + 极短 T → 价格可能低于最小报价单位，clamp 到 `tickSize`

## 4. CDS 保险（P3）

### 4.1 两个方向，你只想到一个

| 方向 | 机制 | 历史原型 | 游戏价值 |
|---|---|---|---|
| **买保护** | 付保费，违约时赔付。损失有限 | 保尔森、各家对冲基金 | 中等 |
| **卖保护** | **收保费**，平时稳赚，危机时一次性爆掉 | **AIG、monolines** | **★★★★★ 精华** |

**卖保护是 2008 年最大的悲剧，也是最好的游戏机制。**

### 4.2 卖保护的三重死亡机制

1. **尾部风险集中**：平时每年稳收几个点，账面漂亮；某天亏损的尾部一次性实现，抹掉整家公司。
2. **抵押品追缴螺旋**：
   ```
   信用利差上升 → 你的空头保护头寸浮亏 → 抵押品要求上升
   同时你的抵押品自身价值下跌
   → 被迫追加抵押品 / 平仓 → 亏损实现 → 信用进一步恶化
   ```
   **AIG 就是这么死的。** 注意这个螺旋里，"你判断对了"也救不了你——是融资断裂杀的。
3. **对手方风险（CVA）**：如果你**买**的是 AIG 的保护，而 AIG 在 2008-09-16 被救助/接近违约——**你的保险可能赔付不了。**

   ```
   保护的实际价值 = 名义赔付 × (1 − 对手方违约概率)
   ```
   买保险的人也会死。**这是 2008 年最反直觉、也最值得教会玩家的一课。**

## 5. 保证金与强平

### 5.1 逐日盯市

```
equity(t) = cash + Σ (position_qty × mark_price(t))
maintenance_margin = Σ (|qty| × price × mm_rate) + Σ (衍生品风险敞口 × rate)
```

### 5.2 强平流程

```
if equity < maintenance_margin:
    → 发出追保通知（margin call），给定补足期限（T+1）
    → 玩家可选择：补钱 / 主动减仓
if equity < maintenance_margin × 0.8 and 未补足:
    → 强制平仓（按最不利于玩家的顺序，且带额外滑点）
    → 若强平后 equity < 0 → 爆仓，游戏结束
```

**强平的成交价必须加惩罚性滑点**（例如正常滑点的 2 倍）。真实世界的强平总是发生在最糟的价格上。

### 5.3 做空的额外约束

| 约束 | 说明 |
|---|---|
| 借券费 | 年化，随拥挤度上升。危机中金融股借券费可达 20%+ |
| 借不到券 | `shortable = false` 时拒单。危机中经常发生 |
| 无上限亏损 | 空头亏损无理论上限，保证金会持续膨胀 |
| 强制回补 | 出借人要求归还 → 你被迫买入 → 推动价格上涨（逼空燃料） |

### 5.4 融资（P2+，一等公民）

```
repoCapacity   = 抵押品价值 × (1 − haircut)
haircut        平静期 2–5%，危机期 40–100%
```

**回购市场的挤兑是本作最被低估的机制。** 2008 年真正杀死机构的是：抵押品还能用，但 haircut 从 5% 涨到 45%，一夜之间融资缺口出现，被迫抛售。

**玩家的核心资源不只是现金，还有"融资能力"。** 让"融资能力"显示在主界面上，而不是藏在二级菜单里。

## 6. 流动性与冲击成本

### 6.1 市场容量

```
V(t) = ADV20 × L(t)                L(t) ∈ [0.05, 1.0]
```
- `L(t)` = 流动性状态，平静期 ≈ 1.0，恐慌期 ≈ 0.05–0.15
- `ADV20` = 20 日平均成交量（只用历史，防未来函数）

**恐慌时市场容量只剩 5%。这意味着你昨天能卖的仓位，今天卖不掉。**

### 6.2 平方根冲击律（真实的市场微观结构经验规律）

```
impact = η × σ_daily × √(Q / V)
成交价 = 开盘价 × (1 ± impact)        方向永远对玩家不利
η ≈ 0.5–1.0
```

`Q` = 你的订单量，`V` = 当日市场容量。

**为什么用平方根而不是线性**：线性冲击会让大资金完全无法行动，平方根是实证规律（Almgren-Chriss / Bouchaud 等），且它有一个漂亮的性质——**规模越大，边际成本越高，但不会高到完全无法交易**。这正好制造"能做，但每多做一点都更痛"的张力。

### 6.3 部分成交与滑点分级

| Q / V | 结果 |
|---|---|
| < 5% | 全额成交，滑点可忽略 |
| 5–25% | 全额成交，明显滑点 |
| 25–100% | 部分成交（约 30–60%），大滑点 |
| > 100% | 几乎不成交，`reason: 'insufficient_liquidity'` |

**"想跑跑不掉"必须是玩家能真实体验到的挫败。** 它是本作最重要的情绪设计。

## 7. 股指期货

最简单的一类衍生品：

```
合约价值 = 指数点位 × multiplier
保证金   = 合约价值 × margin_rate
每日结算 = 现金划转（mark-to-market）
```

- 提供杠杆，但同样有逐日结算与追保 → **杠杆的痛感来自每日现金流，不是账面浮亏**
- 期货与现货存在基差，危机中基差剧烈波动
- 到期移仓（roll）

## 8. 系统性风险分与监管阶梯 ★

> 这一节回应用户提出的想法：**玩家资金过大时会自己引入波动，并可能引来 SEC 介入。**

### 8.1 设计立场

监管**不是**"系统针对玩家"的惩罚机制。它是：

- **状态相关的**：由玩家自己的行为积累而成
- **有滞后的**：监管永远慢半拍（真实）
- **正反两面的**：做空禁令会锁死空头，但也在保护持有多头的人
- **会误伤的**：你可能不是主因，却被一起禁了（真实）

**核心闭环：玩家越成功（做空赚得越多），SRS 越高，监管越可能出手，最终在最高难度下把玩家的策略直接锁死。** 玩家会成为自己成功的受害者。

这完美符合"NPN 不针对玩家"的原则——**监管不是狙击，是玩家自作自受的涌现结果。**

### 8.2 系统性风险分（SRS）

```
SRS = w1·空头集中度 + w2·杠杆水平 + w3·持仓脆弱度 + w4·市场压力贡献
```

| 分量 | 定义 |
|---|---|
| `空头集中度` | `你的空头股数 / 该股流通股` 的最大值 |
| `杠杆水平` | `gross_exposure / equity`，归一化 |
| `持仓脆弱度` | 对问题机构（利差飙升 / 评级下调）的敞口 ÷ equity |
| `市场压力贡献` | `你的交易造成的价格影响累计 / 市场总跌幅` |

建议权重 `w = [0.35, 0.20, 0.20, 0.25]`。

### 8.3 监管阶梯

| 级别 | 触发 | 效果 | 玩家体验 |
|---|---|---|---|
| **L0 无事** | SRS < 0.20 | — | — |
| **L1 监控** | SRS > 0.20 | 无市场效果。**UI 上出现一个安静的红点** | 免费的紧张感。什么都没发生，但玩家开始不安 |
| **L2 强制披露** | 单一标的空头 > 流通股 5% | 你的仓位被公开 → **其他 NPC 能看到并跟随/反向** | 你的策略暴露了，猎物开始反抗 |
| **L3 交易限制** | SRS > 0.50 | ① 你的保证金要求 ×1.5<br>② 借券费飙升<br>③ **禁止裸空**（必须借到券才可做空） | 策略还在，但成本暴涨 |
| **L4 紧急规则** | SRS > 0.75 且市场跌幅超阈值 | **可能触发临时做空禁令**（历史：2008-09-19 SEC 紧急命令禁止 799 只金融股做空，至 10-08） | **你的核心策略被直接锁死。** 你成了自己成功的受害者 |
| **L5 处置** | `equity < 0` 且系统重要性高 | 救助 / 国有化 / 有序清算（三种结局） | 因为你太大而不能倒，你被救了，但被剥夺了大部分 upside |

### 8.4 UI 透明度要求（关键）

**监管机制必须对玩家可见，否则只是困惑。**

主界面常驻一个「市场足迹」面板：

```
你的系统性足迹
├─ 空头集中度    4.8%   （5.0% 触发强制披露）
├─ 有效杠杆      3.2×
├─ 你造成的跌幅  −6.4%（占市场总跌幅 18%）
└─ 监管关注度    ████░░░░  L2 披露中
```

**透明度本身就是教育。** 玩家看到"我的交易造成了市场 18% 的跌幅"，才会真正理解"规模"是什么意思。

### 8.5 反向情形（必须支持）

- 如果玩家是**多头**，做空禁令反而**救了他**。
- 如果玩家是小资金（D0/D1），SRS 永远接近 0，监管机制完全不激活。
- 监管的滞后意味着：**玩家有机会在 L3 生效前抢先平仓**。这是一个漂亮的决策点。

### 8.6 对称性：做多也能操纵

如果玩家资金极大且做多，同样会推高价格，同样会积累 SRS（只是分量权重不同——操纵市场的调查取代做空禁令）。

**保持机制对称，玩家才不会觉得"系统只惩罚赢家"。**
