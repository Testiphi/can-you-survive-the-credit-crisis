# 01 · 设计总纲

## 1. 定位

**类型**：单人 · 回合制 · 交易模拟 · 历史推演
**舞台**：2007-01-01 → 2009-12-31（约 522 个交易日），可扩展 2010–2012 欧债危机
**形态**：Web 网页，纯前端离线可跑
**一句话**：在一个会崩盘、但你不知道哪天崩的市场里，活下来并赚钱。

### 1.1 教育目标（与娱乐目标并列，不冲突）

通关之后，玩家应该真正理解三件事：

1. **杠杆 + 期限错配 = 死。** 不是你判断错了，是你在正确的时候被融资断了。
2. **流动性是幻觉。** 平时能进出的仓位，在恐慌时不存在。
3. **相关性会在最糟的时刻趋近于 1。** 你以为你分散了，其实没有。

反面目标（要避免教会玩家的）："做空就能发财"。这是最廉价、最错误的结论，也是最容易做出来的游戏。

### 1.2 目标玩家

- 主：对金融/经济有兴趣的普通玩家、学生（D0/D1）
- 核：有交易或金融背景的玩家（D2/D3）
- 不追求：纯休闲玩家。本作的 UI 是"终端美学"，不是手游美学。

## 2. 核心循环

### 2.1 单回合时序（严格单向，禁止回头）

```
[t 日收盘]
   │
   ├─ 展示：t 日 K 线、成交量、指标、新闻（全部 ≤ t 日）
   │        ← 屏幕上 t 日之后是空白，没有未来
   │
   ├─ 玩家决策：下单 / 调仓 / 什么都不做
   │        ← 订单在此刻提交
   │
[t+1 日开盘]
   ├─ 事件注入：按事件卡 DAG + 随机数决定今日是否有事件
   ├─ NPC 决策：各类机构按各自目标行动
   ├─ 市场出价：生成 t+1 日价格（基础路径 + 噪声 + 事件冲击 + 玩家冲击）
   ├─ 成交：玩家订单以 t+1 开盘价 + 滑点成交（可能部分成交 / 完全无法成交）
   ├─ 盯市结算：计算净值、保证金、追保、强平
   │
   └─ 回到 [t+1 日收盘]
```

**铁律：玩家在 t 日看到的只有 ≤ t 日的信息，成交发生在 t+1。** 这是本作的头号死因防线，详见 [02 文档 §7](02-系统架构与数据结构.md)。

### 2.2 时间粒度

| 难度 | 粒度 | 说明 |
|---|---|---|
| D0 | 1 回合 = 1 周 | 降低操作负担，突出"看新闻做判断" |
| D1–D3 | 1 回合 = 1 交易日 | 标准 |

- 平静期提供**"快进到下一个事件/下一次持仓变动超过 X%"**按钮，避免无聊。
- 每回合允许下单数：D0–D2 不限；D3 限制为每回合 N 笔（模拟执行能力上限）。

### 2.3 不可逆性

- **铁人模式（默认开启）**：单一存档，自动保存，不能回退。
- 理由：如果玩家能读档重来，[03 文档](03-金融模型与数值.md) 里精心设计的随机扰动**完全失效**——玩家会试到赢为止。
- 提供"关闭铁人"的开关，但关闭时在结算页标注"本局为休闲模式，不计入成绩"。

## 3. 八条设计原则

1. **难度来自约束，不来自信息。** 信息越多，游戏越简单。
2. **融资断裂是第一公民。** 玩家要管理的不只是现金，还有"能不能融到钱"。
3. **NPC 有自己的目标，不针对玩家。** 痛苦应该是涌现的，不是被狙击的。
4. **随机的是"何时"和"多深"，不是"是否"和"方向"。**
5. **每一个数据/工具都必须改变一个决策。** 否则砍掉。
6. **不可逆性是一切紧张感的来源。**
7. **"被迫卖出"比"主动看空"更重要。** 建模约束，不是建模观点。
8. **判定时点即最优策略。** 明确它，并用多时点计分化解。

## 4. 难度分层

### 4.1 核心认知：难度不是靠加数据

给玩家更多数据是让游戏**更容易**。真正的难度来源只有四种，D0→D3 应该沿着这四条轴加码：

```
难度 = 信息稀缺度 × 交易约束强度 × 对手优势 × 后果不可逆性
```

### 4.2 难度矩阵

| | **D0 看懂危机** | **D1 基本面** | **D2 专业层** | **D3 太大而不能动** |
|---|---|---|---|---|
| 可见信息 | K 线、成交量、大字新闻标题 | + 联邦基金利率、TED 利差、LIBOR-OIS、VIX、失业率、Case-Shiller、收益率曲线 | + 信用利差（CDS 代理）、评级变动、回购市场、财报、机构持仓 | + 订单流异常、做市商报价深度、对手意图线索 |
| 可操作 | 做多 / 做空 / 清仓 | + 保证金、杠杆、借券费 | + 股指期货、期权（15 个合约）、买保护（CDS） | + 卖保护、场外合约（3 种模板）、组合对冲 |
| 初始资金 | 固定小 | 固定中 | 可选 | **可选，且与冲击成本强绑定** |
| 冲击成本 | 无 | 低 | 中 | **极高（你是市场的一部分）** |
| 融资约束 | 无 | 有（保证金） | 有（+ 借券、追保） | 有（+ 回购融资、评级反馈） |
| 监管干预 | 无 | 无 | 偶发规则变化 | **系统性风险分驱动，可对你出手** |
| NPC 行为 | 无 | 跟随趋势 | 五类异质策略 | + 死亡螺旋、流动性抽逃、逼空涌现 |

**D3 的正确形态不是"数据最多"，而是"数据最多但你看不过来、想交易时借不到券、想跑时卖不掉、对手比你早知道三天、你的规模本身会引来 SEC、而且你不能读档"。**

## 5. 玩家身份

身份是**成本极低的难度载体**，决定能做什么、能借多少、有没有赎回压力。

| 身份 | 初始资金 | 特殊约束 | 体验关键词 |
|---|---|---|---|
| 散户 | $10 万 | 无冲击成本，但拿不到好价格；可能被裁员（见 §6.3） | 无力感、旁观巨兽倒下 |
| 对冲基金 | $1000 万 | 有赎回压力；高水位线（亏损后要回本才能提业绩费） | 灵活、但要向 LP 交代 |
| 投行自营 | $10 亿 | 有评级反馈与融资约束；可能自己就是下一个雷曼 | 死亡螺旋 |
| 保险/再保险 | $100 亿 | **可以卖保护**；尾部风险 | AIG 的命运 |

> D0/D1 建议锁定"散户/小基金"；D2/D3 开放全部身份。

## 6. 胜负与评分

### 6.1 为什么不能只比"赚多少钱"

单一目标会导致策略坍缩（全仓做空 = 唯一解）。必须多轴评分。

### 6.2 总分构成

```
总分 = 收益分 + 生存分 + 风控分 + 叙事分 − 惩罚
```

| 分项 | 计算 | 权重 |
|---|---|---|
| 收益分 | 期末净值 / 初始资金，对数化后映射 | 30% |
| 生存分 | 全程未触发强平得满分；每次追保扣分 | 25% |
| 风控分 | 最大回撤、夏普比率、是否踩中"雷"（持有雷曼/两房/AIG 到归零） | 25% |
| 叙事分 | 成就系统（见 §6.4） | 20% |
| 惩罚 | 爆仓 = 直接失败；关闭铁人模式 = 成绩不计入 | — |

**"什么都不做"（空仓保本）必须能拿到中上评分。** 如果空仓 = 垫底，游戏就退化成赌博。

### 6.3 判定时点（重要）

**判定时点决定唯一最优策略。**

- 2009-03-09 标普 676 点是空头的天堂
- 2009-12-31 标普涨到 1115，做空者利润腰斩

**解法：分段结算 + 多时点计分。**
- 在 2007-12、2008-06、2008-12、2009-06、2009-12 各记一次净值快照
- 最终分 = 各段收益的加权（近期权重不高于早期）
- 附带"你如果在 2009-03 就没跑掉"的复盘提示

这样"一路做空到底"和"及时反手"都能得分，但后者得分更高。

### 6.4 成就系统（叙事分）

- 《空头之王》：在雷曼周做空获利
- 《逃顶》：在 2009-03 前平掉空头
- 《铁石心肠》：全程空仓保本
- 《接飞刀的手》：在暴跌中抄底并活着出来
- 《我也是雷曼》：亲身经历死亡螺旋
- 《太大而不能倒》：触发 L5 监管处置

成就本身就是教学。玩家为了拿成就，会主动去体验那些他想避开的机制。

## 7. 路线图

每一期都必须交付一个**可玩**版本。禁止"做到一半才有可玩版本"。

### P0 · 原型（约 1 周）— 验证"手感"

**内容**
- 纯前端，一条真实历史价格路径（标普 500 + 3 只个股）
- K 线 + 成交量
- **只有三个按钮**：做多 / 做空 / 清仓
- 新闻卡（真实历史标题，按日期推进）
- 净值曲线

**验收标准**：不看代码也能感到"看新闻 → 决策 → 承担后果"这个循环是有张力的。

### P1 · 最小可玩版（约 2–3 周）— 验证"机制"

**内容**
- 真实数据接入（FRED 宏观 + 指数 + 合成个股路径）
- 难度 D0 / D1 完整分层
- 保证金、杠杆、做空借券费、逐日盯市、追保、强平
- 事件卡 + 前置条件 DAG + 三层随机扰动
- 铁人模式、种子存档、复盘界面
- **种子对战**（分享种子字符串，比成绩）—— 成本极低，价值极高

**验收标准**
- 金融引擎单元测试全绿
- 确定性回归：`seed=42` + 固定操作序列 → 断言期末净值
- 10000 局蒙特卡洛自动对局跑出合理的净值分布（不能是"全仓做空必赢"）

### P2 · 专业层（约 3–4 周）

**内容**
- 信用利差正反馈机制（不还原数据，做机制）
- 期权：3 个到期日 × 5 个行权价，**IV 与 VIX 严格联动**
- 股指期货
- 流动性 / 冲击成本模型（平方根律）
- 监管规则引擎（做空禁令、提高保证金、熔断）
- NPC 五类异质策略（散户/保守基金/对冲基金/投行/做市商）
- 系统性风险分 SRS + 监管阶梯 L1–L3
- 动态相关性坍缩

**验收标准**：D2 玩家无法通过单一策略通关；"分散化失效"能被玩家亲身体验到。

### P3 · 太大而不能动（约 4 周+）

**内容**
- 投行 NPC 的死亡螺旋与间接信息博弈（订单流可读）
- **卖保护**机制 + 对手方风险 + 抵押品追缴螺旋
- 场外合约（**只给 3 种模板**，不做自由合约）
- 监管阶梯 L4–L5（紧急做空禁令、救助/国有化/清算）
- 玩家冲击驱动的事件卡改写（你亲手制造危机 → 平行时间线）
- 排行榜与账号（此时才需要后端）

### 从 P3 提前到 P1 的三件事

`种子对战`、`铁人模式`、`失败复盘` —— 成本极低，价值极高，不要拖到最后。

## 8. 反模式清单（明确不做）

| 不做 | 原因 |
|---|---|
| 限价订单簿（LOB）撮合模拟 | 工程量爆炸，收益极低。回合制日频不需要 |
| 蒙特卡洛期权定价 | 慢几个数量级。用 BS + 参数化波动率曲面 |
| 还原真实历史期权链 | 数据收费且无免费替代，是研究项目不是功能 |
| 真实 tick 级数据 | 同上 |
| "针对玩家"的 NPC AI | 玩家会感到被系统作弊，挫败退出 |
| 完全自由的场外合约 | 玩家会自己写一份必胜合约 |
| 3D / 角色立绘 / 过场动画 | 单人开发者陷阱。用信息美学替代 |
| 实时多人对战 | 需要后端 + 反作弊，与本作节奏不匹配 |
| 用强化学习训练银行 AI | 研究级难度，启发式策略已经足够好玩 |
| 一开始就做全部难度 | 必然烂尾 |

## 9. 关键取舍速查

| 遇到这个选择 | 选这个 |
|---|---|
| 加更多数据 vs 加更多约束 | **加约束** |
| 更聪明的 NPC vs 更异质的 NPC | **更异质** |
| 更真实的定价 vs 更稳定的定价 | **更稳定**（有 bug 的定价会毁掉游戏） |
| 更刺激的收益 vs 更痛的损失 | **更痛的损失** |
| 让玩家赢 vs 让玩家学到东西 | **让玩家先输一次** |
